Install InfraLens

One native app. Nothing else to run.

Needs a Proxmox VE host with an API token. Ollama is optional, for the assistant.

There's no Windows build yet. InfraLens runs on macOS and Linux.

First launch on macOS

InfraLens isn't notarized by Apple yet, so macOS may block the first launch.

  1. Move InfraLens to Applications.
  2. Run this command: 
    xattr -cr /Applications/InfraLens.app
  3. Open InfraLens and allow Local Network access under System Settings → Privacy & Security, so it can reach your Proxmox host.

Running on Linux

Make the AppImage executable, then run it:

chmod +x InfraLens_0.2.0_amd64.AppImage
./InfraLens_0.2.0_amd64.AppImage

Or install the Debian package:

sudo dpkg -i InfraLens_0.2.0_amd64.deb

Build from source

A Python backend and a React frontend. Run both locally to work on InfraLens itself.

backend 

# Clone the repo
git clone https://github.com/AdamYahmadi/InfraLens.git
cd InfraLens/backend

# Set up the environment
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# Add your Proxmox API token and SSH credentials
cp .env.example .env

# Run
python main.py

frontend 

# Install dependencies
cd InfraLens/frontend
npm install

# Point it at your backend in .env
VITE_API_URL="http://127.0.0.1:8756"

# Start the dev server
npm run dev
